Format PDF (Rekomendasi Utama)

Format standar resmi siap cetak. Bisa langsung dibuka di semua perangkat (HP Android, iPhone, Tablet, maupun Laptop) tanpa merubah tata letak atau font.

💡 Sangat disarankan untuk dibagikan via WhatsApp, email kampus, atau dicetak langsung.

Format Word (.doc)

Berkas dokumen Microsoft Word untuk diedit ulang atau dimodifikasi lebih lanjut di Laptop/PC.

⚠️ Catatan untuk HP: File .doc ini umumnya tidak dapat dibuka langsung di aplikasi bawaan HP. Jika ingin dibuka atau dibagikan lewat HP, silakan gunakan Cetak / Simpan PDF.
